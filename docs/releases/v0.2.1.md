# Private Cloud v0.2.1

这是私有云备份 Android 客户端的 v0.2.1 版本。

## 变更

- 未加密的新快照在 NAS 上保留原目录、原文件名和 WebDAV MIME 类型；旧 `.blob` 快照仍可恢复。
- 首页改为“服务器、备份、恢复、状态”四个 Tab，任务结果会在前台弹出提示并继续保留状态与历史记录。

## 下载说明

- `private-cloud-v0.2.1-release.apk`：仅在维护者配置完整签名 Secrets 时提供，适合升级同一签名的测试安装。
- `private-cloud-v0.2.1-debug.apk`：Android debug 签名测试包，不能无缝覆盖不同签名的安装。
- `private-cloud-v0.2.1.sha256`：所有 APK 的 SHA-256 校验值。

如果没有配置 release 签名，GitHub Release 会被标记为预发布，并且只附带 debug APK。

## 安全提醒

- 使用端到端加密前，请离线保存恢复密钥；丢失密钥后无法恢复加密快照。
- WebDAV 优先使用 HTTPS；不要把 SMB 445 直接暴露到互联网。
- 恢复仍会创建新目录，不会静默覆盖手机上的原文件。
