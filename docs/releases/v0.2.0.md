# Private Cloud v0.2.0

这是私有云备份 Android 客户端的 v0.2.0 版本。

## 新功能

- 多个独立备份方案，以及显式配置保存、加载和安全清理。
- WorkManager 定时备份，可限制为非计量网络、充电且电量充足时运行。
- 最近任务历史、完成通知、分类重试和指数退避。
- 文件、目录与扩展名排除规则。
- 快照浏览、单文件或子目录恢复、手动删除及按数量自动保留。
- 可选的恢复密钥 AES-256-GCM 文件内容加密；旧版未加密快照仍可恢复。
- 可由 GitHub Secrets 提供 keystore，生成经过签名和验证的 release APK。

## 下载说明

- `private-cloud-v0.2.0-release.apk`：仅在维护者配置完整签名 Secrets 时提供，适合升级同一签名的测试安装。
- `private-cloud-v0.2.0-debug.apk`：Android debug 签名测试包，不能无缝覆盖不同签名的安装。
- `private-cloud-v0.2.0.sha256`：所有 APK 的 SHA-256 校验值。

如果没有配置 release 签名，GitHub Release 会被标记为预发布，并且只附带 debug APK。

## 安全提醒

- 使用端到端加密前，请离线保存恢复密钥；丢失密钥后无法恢复加密快照。
- WebDAV 优先使用 HTTPS；不要把 SMB 445 直接暴露到互联网。
- 恢复仍会创建新目录，不会静默覆盖手机上的原文件。
